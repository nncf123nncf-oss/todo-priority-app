# 📋 優先度つきTodoアプリ

タスク名・期限・優先度を登録して管理できる、シンプルなTodoアプリです。
HTML / CSS / JavaScript のみで動作し、データはブラウザの localStorage に保存されます。

## 機能

- タスク名・期限（任意）・優先度（高/中/低）を入力して追加
- 未完了→完了、優先度 高→低、期限が近い順に自動ソート
- チェックボックスで完了/未完了を切り替え（完了は打ち消し線＋薄色表示）
- 削除ボタンでタスクを削除
- 期限切れタスクは赤字で「期限切れ」表示
- localStorage による保存（リロードしてもデータが残る）
- 空欄のままの追加は拒否（エラーメッセージ表示）
- タスクが0件のときは案内メッセージを表示
- スマートフォン対応（レスポンシブレイアウト）

## 使い方

ビルド不要です。`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで開く場合:

```bash
python -m http.server 8000
```

→ http://localhost:8000 にアクセス

## ファイル構成

```
todo-priority-app/
├── index.html   # 画面構造
├── style.css    # スタイル（レスポンシブ対応）
├── app.js       # ロジック（追加・完了・削除・localStorage）
└── README.md
```

## 技術メモ

- タスク名は `textContent` で描画しているため、HTMLタグを入力してもスクリプトは実行されません（XSS対策）
- localStorage のデータは読み込み時に形式を検証するため、壊れたデータがあってもアプリは落ちません
- 外部ライブラリ・APIキー・サーバーは不要です
